# Reference Library

This folder preserves the **original materials supplied for the project** and adds the synthesized **Enterprise AI Strategy & Build Plan** that converts those materials into a build sequence.

> **For an AI or developer:** Do not begin by reading all four original documents. Start with `../product/PRODUCT_BRIEF.md` and `ENTERPRISE_AI_STRATEGY_AND_BUILD_PLAN.md`. Open an original document only when a specific decision needs deeper context.

## Reading order

1. `../../AI_CONTEXT.md` — quick build rules.
2. `../product/PRODUCT_BRIEF.md` — the current product and next build task.
3. `ENTERPRISE_AI_STRATEGY_AND_BUILD_PLAN.md` — the complete project logic.
4. One original document only if the current task needs evidence or details beyond the synthesis.

## Important boundary

The original documents include hypotheses, starting assumptions, and market observations. They are not a substitute for qualified legal, messaging-compliance, finance, accounting, or tax review before a live client deployment.
