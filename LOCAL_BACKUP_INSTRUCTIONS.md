# Local Backup Instructions

## What you are receiving

The local archive contains the application source, strategy/workbook documentation, original project briefs, and the generated visual assets used by the current strategy report. It is a **portable project record**—not a production deployment.

## Save it in three places

1. Download the archive to a folder you control, such as `Documents/Enterprise-AI-Project/`.
2. Keep one copy in a private cloud folder you control, such as Google Drive, iCloud Drive, Dropbox, or OneDrive.
3. After meaningful changes, create a new dated archive rather than overwriting the old one.

## Recommended local folder name

```text
Enterprise-AI-Project/
  01_Original-Research/
  02_Strategy-and-Workbooks/
  03_Product-Demo/
  04_Backups/
```

## How to continue with Fable or Claude

1. Open the copied project folder in your preferred coding environment.
2. Read `SOURCE_OF_TRUTH.md` first.
3. Copy the **Start-of-session prompt** from `FABLE_CLAUDE_PROMPTS.md` into your implementation session.
4. Give the AI only the current build task.
5. Test the result, record the outcome in `DECISION_LOG.md`, and save a dated backup.

## Important limitations

The code is a static demonstration project at this stage. It does not include real customer-data connections, live message delivery, production authentication, or completed compliance review. Those are post-sale implementation work and should be handled with appropriate client authorization and qualified review.
