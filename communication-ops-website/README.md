# Communication Ops Website

This directory contains the standalone marketing website task for the Communication Ops product. The design direction is documented in [`ideas.md`](ideas.md). The site speaks to distributor sales and operations leaders who need a clearer, human-owned way to prepare and govern account communication work.

The website uses fictional workflow examples only. It must not imply live integrations, customer delivery, policy approval, regulated communication authorization, or guaranteed commercial outcomes.
